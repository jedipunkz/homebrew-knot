# homebrew-knot

Homebrew tap for [knot](https://github.com/jedipunkz/knot), a terminal UI for Git.

## Install

Use the full name: `knot` alone is the Knot DNS server in homebrew-core.

```sh
brew tap jedipunkz/knot
brew install jedipunkz/knot/knot
```

## Update

```sh
brew upgrade jedipunkz/knot/knot
```

`Formula/knot.rb` is updated by the release workflow of jedipunkz/knot.
